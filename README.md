Plutus provides a cloud cost optimization platform that automatically discovers savings in cloud and AI spend, creates draft pull requests with infrastructure changes, and lets users review and merge them. The service integrates with Terraform on AWS, supports multiple plans with self‑serve pricing, and offers features like SSO, SCIM, and detailed cost tracking across resources. It aims to reduce cloud bills without taking a percentage of savings.

**Areas:** Cloud · Cost Optimization · AI · Terraform · SaaS

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Plutus: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
